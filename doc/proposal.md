# 網路水軍評論偵測系統 — 研究提案

**版本：** v1.0  
**日期：** 2026-06-03  
**性質：** 學術研究 / 論文  

---

## 1. 研究背景與動機

隨著社群媒體與影音平台的普及，網路水軍（Astroturfing）問題日益嚴重，尤其在政治與時事議題上，協同操控輿論的行為嚴重影響公共討論品質。YouTube 作為繁體中文用戶大量聚集的平台，其留言區已成為水軍活動的重要場域。

本研究針對 YouTube 政治/時事頻道留言，開發一套基於機器學習的水軍偵測系統，透過多維度特徵分析，對留言與用戶帳號同時進行水軍風險評估。

---

## 2. 研究目標

1. 建立一套可重現的 YouTube 政治頻道留言資料收集流程
2. 設計有效的水軍行為特徵提取方法
3. 訓練並比較多種機器學習模型的偵測效果
4. 輸出可用於論文引用的量化實驗結果

---

## 3. 偵測對象定義

本研究定義以下四類水軍行為：

| 類型 | 描述 | 主要判斷依據 |
|------|------|------------|
| **Bot 機器人帳號** | 自動化程式產生的留言 | 發文間隔極短、內容高度重複、零互動 |
| **付費刷評論** | 業配、廣告、行銷留言 | 含廣告關鍵字、夾帶連結、格式化模板 |
| **協同操控輿論** | 多帳號推同一立場 | 時間群聚、內容相似、集中針對特定影片 |
| **垃圾/重複內容** | 無意義或大量複製的留言 | 高自我相似度、極短或無意義文字 |

## 5. 特徵工程

所有特徵以**用戶帳號（author_id）**為單位計算，使用固定 **7 天回溯窗口**，確保訓練與推論特徵一致。

### 5.1 行為特徵

| 特徵名稱 | 計算方式 | 水軍信號 |
|----------|----------|---------|
| `total_comments` | 7 天內總留言數 | 數量異常高 |
| `unique_videos` | 留言涉及的不同影片數 | 數量極少（集中刷單一影片） |
| `concentration` | `total_comments / unique_videos` | 值越高越集中 |
| `avg_likes` | 平均每則留言按讚數 | 水軍留言通常獲讚極低 |
| `zero_like_ratio` | 零按讚留言比例 | 比例越高風險越高 |
| `max_burst` | 單小時最大留言量 | 短時間爆量發文 |

### 5.2 內容特徵

| 特徵名稱 | 計算方式 | 水軍信號 |
|----------|----------|---------|
| `avg_length` | 平均留言字數 | 過短（垃圾）或固定長度（模板） |
| `unique_content_ratio` | 不重複留言數 / 總留言數 | 值越低重複性越高 |
| `self_similarity` | TF-IDF + cosine similarity 均值 | 值越高內容越相似 |
| `has_ad_keywords` | 是否含廣告關鍵字 | 業配水軍指標 |
| `url_ratio` | 含 URL 留言比例 | 垃圾連結 |

> **廣告關鍵字清單：** 訂閱、點擊連結、私訊我、加LINE、賺錢、免費領取、點我、私我、合作、業配

### 5.3 時間特徵

| 特徵名稱 | 計算方式 | 水軍信號 |
|----------|----------|---------|
| `night_ratio` | 凌晨 0-6 點留言比例 | 機器人不休息 |
| `interval_std` | 留言時間間隔的標準差 | 值越低越像機器人（等間隔發文） |

## 6. 標注方法

### 6.1 自動啟發式標記（初始標籤）

由於無現成標記資料集，採用啟發式規則自動產生初始標籤：

**水軍條件（同時滿足以下條件）：**
- `concentration > 5`（集中在少數影片）
- `self_similarity > 0.7`（內容高度重複）
- `zero_like_ratio > 0.8`（幾乎無人互動）
- `interval_std < 60`（發文間隔過於規律，秒數）

**正常用戶條件：**
- `unique_videos >= 3`
- `self_similarity < 0.3`
- `zero_like_ratio < 0.5`

不滿足上述任一條件的樣本標記為**待人工複審**，不納入初始訓練集。

### 6.2 人工複審

針對模型預測結果不確定（機率 0.4–0.6）的樣本進行人工複審，補充高品質標記資料。

### 6.3 標注粒度

| 層級 | 標籤 | 說明 |
|------|------|------|
| **用戶層級** | `is_bot`（0/1） | 該帳號是否為水軍 |
| **留言層級** | `is_spam`（0/1） | 該則留言是否為水軍內容 |

## 7. 機器學習方法

採用三階段遞進式方法，逐步提升模型複雜度與準確率。

### 第一階段：傳統機器學習（Baseline）

**目標：** 驗證特徵有效性，建立效能基準

| 模型 | 用途 |
|------|------|
| Logistic Regression | 特徵重要性分析、建立 baseline |
| XGBoost | 追求更高準確率 |

**輸入：** 5.1~5.3 節的數值特徵向量  
**輸出：** 用戶層級水軍機率分數

### 第二階段：中文 BERT 語意模型

**目標：** 加入留言文字的語意理解能力

| 模型選項 | 說明 |
|----------|------|
| MacBERT | 繁體中文效果佳 |
| RoBERTa-wwm-ext | 簡繁混合語料 |
| BERT-wwm-ext | 全詞遮罩預訓練 |

**輸入：** 單則留言文字  
**輸出：** 留言層級水軍機率分數

### 第三階段：多模態融合（進階）

**目標：** 結合帳號行為 + 文字語意，提升協同操控偵測能力

- 將第一、二階段輸出合併作為融合模型輸入
- 選擇性加入 GNN（Graph Neural Network）分析帳號互動網路

---

## 8. 評估指標

| 指標 | 說明 | 目標值 |
|------|------|--------|
| **Precision** | 預測為水軍中真正水軍的比例 | ≥ 0.80 |
| **Recall** | 實際水軍被正確找出的比例 | ≥ 0.75 |
| **F1-Score** | Precision 與 Recall 的調和平均 | ≥ 0.78 |
| **AUC-ROC** | 模型整體分辨能力 | ≥ 0.85 |

> **注意：** 由於資料不平衡（水軍比例遠低於正常用戶），主要以 F1-Score 作為模型選擇依據，而非 Accuracy。

## 10. 專案限制與風險

| 限制 | 說明 | 因應方式 |
|------|------|---------|
| API 配額限制 | 10,000 units/day，約可收集 1,000 則留言 | 分多天收集，或申請提升配額 |
| 標籤品質 | 啟發式規則可能產生錯誤標籤 | 人工複審不確定樣本 |
| 資料不平衡 | 水軍樣本遠少於正常樣本 | 使用 SMOTE 或調整 class_weight |
| 語言多樣性 | 繁簡混用、口語、縮寫 | 使用全詞遮罩中文 BERT |
| YouTube 政策 | 部分頻道關閉留言或限制 API 存取 | 擴大候選頻道清單 |
